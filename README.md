# TempMail Persian Persistent

ایمیل موقت با ویژگی‌های درخواستی:

- آدرس ایمیل **ثابت می‌ماند** تا وقتی دکمه «ایجاد ایمیل جدید» زده نشود (حتی بعد از بستن برنامه یا تعویض اپ).
- از لیست کلمات (Hopton, Hampstead, Campimello, Vascocombe, Parna, Medigue, Kodesh, Ropajawa, Katlin, Besan, Fakat, Azhamon, Saite) برای ساخت نام کاربری استفاده می‌کند.
- اتصال واقعی به سرویس mail.tm
- کپی یک‌کلیکی آدرس و کدهای داخل ایمیل
- رابط کاملاً فارسی
- قابل نصب روی اندروید به عنوان PWA

## استفاده فوری روی اندروید

1. فایل `index.html` را دانلود کن.
2. با مرورگر Chrome باز کن.
3. منوی سه‌نقطه → **Add to Home screen** / «افزودن به صفحه اصلی».
4. مثل یک اپ واقعی کار می‌کند و ایمیل را حفظ می‌کند.

## ساخت APK

### روش ساده (پیشنهادی):
- برو به https://www.pwabuilder.com
- آدرس ریپازیتوری یا فایل index.html را بده و APK بساز.

### روش حرفه‌ای:
با Android Studio یک پروژه WebView بساز و این index.html را داخل assets بگذار.
